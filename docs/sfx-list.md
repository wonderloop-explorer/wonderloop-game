# 원더룹 효과음 목록 — 공통 묶음과 세계 전용

2026-11-05, 시리즈 공통 틀 6단계. 코드: `js/sfx/common.js`(공통), `js/sfx/<세계>.js`(세계 전용), 목록 `js/sfx/index.js`, 트는 곳 `js/game/sound.js`.

## 먼저 알아 둘 것
- **효과음은 모두 코드로 만든다.** 개미굴 원본(antvillage `index.html`)의 `sfx()` 27개도 모두 Web Audio 코드이고, 원본 안의 소리 파일은 목소리(나레이션·대사)뿐이다.
  - 그래서 "옮기기"는 소리 정의를 `js/sfx/`로 모으고 종류 이름을 붙이는 일이었다. 소리 자체(음·길이·세기)는 원본 그대로다.
  - 녹음·생성한 소리 파일로 바꿀 때 쓸 자리는 `assets/sfx/common/`·`assets/sfx/<세계>/`에 만들어 두었다(지금은 비어 있음).
- **원본 다음은 원더룹 것.** 새 엔진은 원본 `dex` 대신 원더룹에서 만든 `dex`(팅-팅 오름)를 써 왔다. 그대로 두고, 원본 `dex`는 개미굴 전용 `ant-dex`로 남겼다.
- **새로 만든 소리는 원본에 없던 종류 6개뿐이다**: 발소리 바닥 네 가지, 말풍선 뜸, 길 열림. 아직 아무 데서도 틀지 않는다(원본에 없던 소리라 기존 장면을 바꾸지 않으려고). 새 세계에서 쓴다.

## 부르는 법
```js
G.sound.sfx('item-get');            // 종류 이름으로
G.sound.sfx('step-grass',{cue:false}); // 잦은 소리는 시점 기록에서 빼기
G.sound.sfx('talk-bubble',{minor:true}); // 동시 소리가 많으면 건너뛰어도 되는 소리
```
- 옛 이름(개미굴 sfx 이름 `itemget`·`click`·`chime` …)도 받는다. 그러면 종류 이름으로 바꿔 튼다.
- 시점 기록(`cues.json`)의 `id`는 종류 이름이다. 세계가 바꿔 끼웠으면 실제 소리를 `as`에 적는다.

## 이름 규칙
- 소문자와 줄표(-)만 쓴다. 앞부분은 묶음이다.
  - 화면: `ui-`, `mission-`, `item-`, `card-`, `zone-`
  - 움직임: `step`(바닥은 `step-<바닥>`), `jump`, `land`, `dash`
  - 대화: `talk-`
  - 사건: `event-`
  - 날씨: `weather-`
- 세계 전용은 `<세계 약칭>-<이름>`이다(개미굴은 `ant-alert`처럼).
- 같은 종류는 이름 규칙과 크기를 맞춘다. 같은 묶음 원본 소리와 아래 표의 "크기"가 3dB 안이어야 한다.

## 세계에서 바꿔 끼우기
세계 설정(`js/worlds/<세계>.js`, 또는 구역 세계 기본값 `world`)에 `sfx`를 둔다.
```js
sfx:{'item-get':'ant-dex',                          // 다른 소리 이름으로
     'mission-start':'assets/sfx/antvillage/mission.mp3'} // 또는 소리 파일로
```
- 08 `zoneLook`이 구역마다 `sound.useWorld(세계 id, sfx)`를 부른다.
  - 그 세계 전용 묶음(`js/sfx/<세계>.js`)을 켜고, 적은 종류만 바꾼다. 나머지는 공통 묶음 그대로다.
- 지금은 어느 세계도 바꿔 끼우지 않는다.

## 새 소리를 추가하는 방법
1. 공통 묶음 표(아래)에 같은 종류가 있는지 먼저 본다. 있으면 그것을 쓴다.
2. 없으면 어디에 둘지 정한다.
   - 모든 세계에 쓸 소리는 `js/sfx/common.js`의 `NEW`와 `KINDS`에 한 줄씩 넣는다.
   - 그 세계에만 맞는 소리는 `js/sfx/<세계>.js`를 만든다(`antvillage.js` 모양). `js/sfx/index.js`의 `WORLD_SFX`에 한 줄 넣는다.
3. 촬영 서버를 띄운 채 `python3 tools/sfx-loudness.py`로 크기를 잰다. 같은 묶음 원본과 3dB 안이 되게 세기를 맞춘다.
4. 파일 소리로 바꿀 때는 이렇게 한다.
   - 공통 소리: `assets/sfx/common/<종류>.mp3`를 두고 `js/sfx/common.js`의 `FILES`에 적는다. 파일을 읽기 전과 못 읽었을 때는 코드 소리가 난다.
   - 세계 소리: `assets/sfx/<세계>/…`를 두고 세계 설정 `sfx`로 가리킨다.
5. 이 문서 표를 고친다(`docs/sfx-loudness.json`도 다시 만든다).

## 목록
"크기"는 가장 큰 50ms 구간의 RMS(dBFS)다. 묶음 버스(효과음 0.9·전체 0.85)는 빼고 잰 값이며, 무작위가 섞인 소리라 6번 평균이다(`tools/sfx-loudness.py` → `docs/sfx-loudness.json`). "그 원본 소리가 개미굴에서 쓰인 곳"은 원본 `index.html` 기준이다.

- 2026-11-06(공통 틀 8단계): 사건에 종류 이름 다섯(`guard-notice`·`guard-alert`·`guard-windup`·`guard-caught`·`big-get`)을 더했다 — 새 소리는 없고 원본 소리를 가리킨다. 공통 묶음에는 들킴·잡힘 소리가 없어 가까운 원본 소리를 두고, 개미굴은 세계 설정 `sfx`로 원본 `ant-alert`·`ant-windup`·`ant-caught`를 끼운다.
- 원본 소리 하나를 여러 종류가 가리킬 수 있다. 원본이 그렇게 썼기 때문이다(`pickup` = 창 열기·물건 줍기·톡 돌아감, `blip` = 말 걸기·대사 넘김, `click` = 단추·창 닫기, `dex` = 카드·가방).
- 원본 발소리 `step`(-54.5)과 마른 잎 `crunch`(-43.5)는 원래 11dB 차이가 난다. 원본 그대로 두었고, 새 바닥 발소리 넷은 `step`에 맞췄다.
