# 무한 우주 쉼터 토성 고리 — 흐름과 대사 자리

2026-11-24 판. STAGE 3(구름 행성)과 STAGE 4(붉은 폭풍) 사이의 번호 없는 쉼터. 금성에서 얼음 배를 타고 와서 쉬었다가, 목성의 붉은 폭풍 빛에 끌려 떠난다.
대사는 모두 **[임시]**(목소리는 나중에 한꺼번에 녹음) — 게임 글에는 앞에 `[임시]`가 붙어 나오고, `docs/voice/script.csv`에는 상태 '임시'로 적혀 있다(색인에 안 들어가 글자만 나옴).
코드: `js/zones/space/saturn.js`(맨 위 주석), 목성 임시 구역 `js/zones/space/jupiter.js`, 시험·촬영 `tools/space-rest-test.py` → 모음 `tools/space-rest-sheets.py`.

## 흐름 (자동 플레이 기준 약 2분 30초 — 도착 → 붉은 빛이 내려올 때까지)

| 순서 | 일어나는 일 | 대사 자리 |
|---|---|---|
| ① 도착 | 얼음 배가 내려와 섬에 닿음(이동 음악 해결 화음). 둘이 카메라 쪽을 보고 내림, 배는 떠올라 사라짐 | 나레이션 SPC-RS-001(확정·녹음 완료) |
| | 나레이션이 끝나면 거꾸리가 말을 검(대화 카메라, 이동 잠금) | SPC-RS-003 → SPC-RS-004 |
| ② 얼음 고리 던지기 | 원더룹이 던지는 자리로, 거꾸리는 옆으로. 카메라는 원더룹 뒤쪽 비스듬한 위(뿔 셋이 다 보임). 놀이 곡. 할 일 '얼음 고리를 걸어요 n/3' | 안내 문구 SPC-RS-005(글자만) |

| | 셋 다 걸면 원더룹이 카메라 쪽을 보고 폴짝 두 번(앞모습) | SPC-RS-006 |
| ③ 앉아서 쉬기 | 큰 얼음 조각에 둘이 나란히 앉음. 화면 글자·단추 모두 숨김, 대사 없음(40초). 카세트를 꺼내 켬 → 지나온 길의 소리 약 25초 | (없음) |
| ④ 발견 카드 | 거꾸리 한마디(대화 카메라) → 발견 카드 '토성은 물보다 가벼워요'(화면 아래쪽, 토성과 둘이 카드 위에 보이는 구도) | SPC-RS-007 → SPC-RS-008 |
| ⑤ 인사 | 거꾸리 작별 → 얼음 배가 떠 옴 → 거꾸리가 타고 손 흔들며 멀어짐(원더룹 옆모습 너머) → 배 쪽에서 돌아본 원더룹 앞모습(손 흔들기) | SPC-RS-009 |
| 목성으로 | 하늘에서 붉은 소용돌이 빛이 내려와 감싸 올림 → 행성 이동 공통 틀(13초) → 우주 지도(토성 → 목성 발자국) → 붉은 덮개 → 목성 임시 구역 | 지도 자막 SPC-TR-006 |
| 목성(임시) | 줄무늬 구름 위에 사뿐히 내려앉고 '다음 이야기 준비 중' 카드 | SPC-RS-010(글자만) |

중간에 나갔다 오면 끝낸 단계 다음부터 이어진다(`rest:met` · `rest:toss` · `rest:sat` · 발견 · `clear:space-saturn`). 끝낸 뒤 다시 오면 거꾸리는 없고, 섬 가운데 붉은 빛에 들어서면 다시 목성으로 떠난다.

## 쉬기 장면 카메라 다섯 구간 (초 — 앉은 뒤)

| 구간 | 초 | 화면 |
|---|---|---|
| 1 | 0 ~ 8 | 둘의 옆모습(조금 앞쪽에서 — 정옆이면 거꾸리가 원더룹을 가림) |
| 2 | 10 ~ 17 | 둘 너머로 끝없이 이어진 고리 얼음 들판과 아주 작아진 해 |
| 3 | 19 ~ 25 | 둘의 뒷모습 너머 멀리 작은 달 엔켈라두스와 반짝이는 얼음 분수 |
| 4 | 28 ~ 33 | 높이 올라가 고리를 두른 토성 → 북극의 육각형 폭풍으로 다가감 |
| 5 | 36 ~ 40 | 다시 둘에게(앞모습) |

10초 뒤부터 화면을 누르면 '건너뛰기' 단추가 3.5초 동안 뜨고, 그 단추를 누르면 건너뛴다(그 전에는 눌러도 아무 일 없음).

## 카세트 소리 차례 (켠 뒤 초)

딸깍·테이프 → 달: 떡방아 쿵 세 번(2~4) · 아기 토끼 웃음(5~6) → 화성: 바람(8) · 삐삐 웃음(9.6) · 둥둥 웃음(10.7) · 바람(12) → 금성: 생일 노래 두 구절(15~21) · 양 음매 둘(21.6~23) → 딸깍(24.6), 그 뒤 조용.
모두 지금 있는 효과음으로 엮었고, 웃음소리만 새로 만든 효과음(`voice-giggle`)이다. 실제 캐릭터 웃음 녹음이 생기면 바꿔 끼울 자리(saturn.js `TAPE`).

## 사실 기준

- 토성 고리: 지름 수십만 km, 두께는 대체로 10m 안팎, 물얼음 조각들(NASA).
- 토성의 평균 밀도는 물보다 낮다(태양계 행성 가운데 하나뿐).
- 토성 북극에는 육각형 모양의 제트기류(구름 띠)가 있다(NASA) — 게임에서는 잘 보이게 실제(북위 약 78°)보다 조금 크게 그렸다.
- 엔켈라두스 남극의 얼음 분수가 토성 E 고리의 재료가 된다(NASA).
- 토성에서 보는 해는 지구에서보다 훨씬 작다(지름 약 1/10).
- 목성의 대적점은 지구보다 큰 폭풍이다.
