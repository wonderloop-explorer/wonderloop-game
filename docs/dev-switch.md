# 개발용 스위치와 기록 초기화 (2026-11-27)

## 스위치: 장소 고르기를 늘 열어 두기
- 위치: `js/config.js` 맨 위 `const SWITCH=true;` — 이 값 하나.
- `true`(지금 — 개발 중): 시작 화면에 **장소 고르기**가 늘 보이고, 모든 장소(목성 포함)를 잠금 없이 바로 골라 갈 수 있다. '처음부터'는 탐험 지도 화면 맨 아래에 있다.
- `false`(정식 공개 전에 바꿈) — 처음 하는 사람 규칙:

| 기록 | 시작 화면 단추 |
|---|---|
| 없음 | [시작하기] [조작법] — 달부터 순서대로 |
| 하다 만 기록 | [이어서 하기] [처음부터] [조작법] — 처음부터는 한 번 더 물음 |
| 마지막 장소(목성)까지 다녀옴 | [이어서 하기] [장소 고르기] [처음부터] [조작법] |

  - 탐험 준비(옷 고르기)의 '모험 지도'와 게임 중 메뉴 '탐험 지도'도 같은 규칙: 다 마치기 전에는 보기만(고를 수 없음).
  - 지도의 잠금 안내("다른 행성을 모두 다녀오면 열려요")도 이때만 나온다.
- 미리 보기: 스위치를 바꾸지 않고 주소에 `?devopen=0`(또는 `&devopen=0`)을 붙이면 그 페이지에서만 꺼진 모습으로 열린다(`devopen=1`은 켠 모습).
- 바꾼 뒤에는 평소처럼 `python3 tools/stamp.py` → 커밋 → 푸시, 한 파일 HTML도 다시 빌드.

## 기록 초기화: `?reset`
- 주소 끝에 `?reset`(이미 `?`가 있으면 `&reset`)을 붙여 연다.
  - 예: `https://wonderloop-explorer.github.io/wonderloop-game/?world=infinite-space&reset`
- 이 브라우저에 저장된 원더룹 기록(진행·가방·발견·친구 카드·옷·설정 — 이름이 `wl-`로 시작하는 것 모두)을 지우고, `reset`을 뗀 주소로 다시 열린다 → '처음 하는 사람' 상태.
- 기기·브라우저마다 따로 해야 한다(PC 크롬과 아이폰 사파리는 저장이 따로다).
- 유튜브 녹화 전: ① `?reset`으로 열어 기록 지우기 → ② (스위치가 켜져 있으면) `&devopen=0`을 붙여 처음 하는 사람 화면으로 녹화.
